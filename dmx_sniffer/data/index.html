Режим тестирования

Сниффер (приём DMX)
При включении появляется соответствующая вкладка. DMX Тестер — передача DMX данных на шину. WS2812 — прямое управление светодиодами. Кнопка «Рабочий режим» — безопасный возврат к снифферу.

Кол-во каналов DMX

DMX512 — стандартный протокол, 512 каналов на вселенную.
Расширенные режимы (1024–4096) — используются китайскими производителями (KDM, DMX1024/2048/4096). UART передаёт до 4096 байт данных после Start Code. Скорость остаётся 250 кбит/с — увеличение объёма данных за счёт удлинения кадра.

UART Линия 1

250000 — стандарт DMX512/1990. 500000 — удвоенная скорость (нестандарт). 1000000 — максимальная скорость UART (Art-Net/sACN).

LED лента

WS2812B — 1000 светодиодов на GPIO23 (RMT, 8 МГц). Реверс — меняет порядок пикселей (первый становится последним). Полезно когда лента подключена с конца.

Приборы (DMX)

Прибор = один RGB/RGBW.fixture. Каналов — 3 (стандарт RGB) или 4 (RGBW). Порядок — как DMX каналы распределяются по цветам WS2812.

Маппинг

Справка по DMX512

DMX512 — цифровой протокол управления освещением (ANSI E1.11). Работает через RS-485 (2 провода: A, B + GND).

Структура кадра:
— Break (минимум 88 мкс) — низкий уровень, начало кадра
— MAB (минимум 8 мкс) — высокий уровень, пауза после Break
— Start Code (1 байт) — 0x00 = DMX512
— Данные (1–512 байт) — значения каналов, каждый байт = 0–255

Скорость: 250 000 бит/с (250 кбит/с). Формат: 8N2 (8 данных, нет чётности, 2 стоп-бита).
Размер кадра: от 2 до 514 байт (1 Start Code + 1–512 данных).

Один кабель = 512 каналов. Каждый канал — значение 0–255. Управляет яркостью, цветом, позицией и т.д.

Расширенные DMX режимы (1024–4096)

Китайские производители (KDM,某些其他) выпустили собственные стандарты с увеличенным количеством каналов:

DMX1024 — 1024 канала (2 вселенных в одном кадре)
DMX2048 — 2048 каналов
DMX4096 — 4096 каналов (4 вселенных в одном кадре)

Принцип работы: стандартный UART кадр просто удлиняется. Break + Start Code + 4096 байт данных. Скорость остаётся 250 кбит/с. Приёмник должен уметь принимать длинные кадры (UART FIFO + буфер).

Важно: при 4096 каналах время передачи одного кадра увеличивается. При 250 кбит/с: 4096 * 10 бит = ~164 мс на кадр (~6 Гц).
